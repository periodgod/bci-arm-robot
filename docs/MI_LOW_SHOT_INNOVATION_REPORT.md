# 低校准样本 MI 模型创新与严格确认

## 1. 数据资产

当前左右手运动想象数据为一个数据集族：PhysioNet EEGMMIDB。

- 受试者：S001-S020，共 20 人。
- 原始文件：60 个 EDF，每人 runs 4、8、12。
- 标准 trial：900 个，其中左手 455、右手 445。
- 信号：64 通道，160 Hz，每个 trial 3 秒。
- 模型输入：21 个 FC/C/CP 运动区通道，8-30 Hz。

原始 EDF 和派生 NPZ 是同一批信号的两种表示，不重复计数。完整清单见 `docs/MI_DATASET_INVENTORY.md`。

## 2. 功能缺口

普通 CSP-LDA 在每类只有 2-16 个校准 trial 时存在两个问题：

1. 目标受试者类别协方差估计方差很大，CSP 空间滤波器不稳定。
2. 等权使用其他受试者会引入与目标个体不相似的空间模式。

实验假设：使用与目标校准协方差更相似的源受试者，并让先验强度随目标样本数自动衰减，可以降低小样本方差；在 CSP 特征空间进一步使用源类别原型，可以改善极低样本分类。

## 3. 严格实验协议

- 固定源库：S001-S010。
- 模型选择：目标 S001，源 S002-S010。
- 全新确认：S011-S020。
- S011-S020 不参与源库、`kappa` 选择或模型设计。
- 每类校准样本数：2、4、6、8、12、16。
- 每个预算执行 12 次分层随机采样。
- 测试集为目标受试者未进入校准集的全部剩余 trial。
- 每次随机划分对所有模型完全相同。
- 超参数只在 S001 的 2-8 shot 上选择，得到 `kappa=8`。

## 4. 模型

### 4.1 trial 协方差

对预处理 trial `X_i in R^(C x T)`：

`C_i = X_i X_i^T / tr(X_i X_i^T)`。

### 4.2 源受试者相似度

目标校准平均协方差为 `R_t`，源受试者 `s` 的平均协方差为 `R_s`。使用仿射不变 Riemann 距离：

`d_s = ||log(R_t^(-1/2) R_s R_t^(-1/2))||_F`。

相似度权重为：

`w_s = exp(-d_s^2 / median_j(d_j^2)) / sum_l exp(-d_l^2 / median_j(d_j^2))`。

因此和目标空间统计更接近的源受试者贡献更大。

### 4.3 样本预算自适应先验

源类别协方差：

`P_c = sum_s w_s S_(s,c)`。

目标类别协方差为 `T_c`。每类有 `n` 个校准 trial 时：

`alpha(n) = kappa / (n + kappa)`，其中 `kappa=8`。

`Sigma_c = (1-alpha) T_c + alpha P_c`。

当样本少时依赖源先验；样本增加时逐渐回到目标个体统计。`kappa` 可解释为源协方差提供的等效每类 trial 数。

### 4.4 CSP 与层级类别原型

CSP 求解：

`Sigma_1 w = lambda (Sigma_0 + Sigma_1) w`。

取最大和最小特征值方向各 3 个，得到 6 个 log-variance 特征。

目标类别原型为 `m_(t,c)`，相似度加权源原型为 `m_(s,c)`。层级收缩为：

`m_c = (n_c m_(t,c) + kappa m_(s,c)) / (n_c + kappa)`。

共享特征协方差同样向源受试者类内协方差收缩，再使用线性判别函数：

`g_c(z) = z^T Sigma_f^(-1) m_c - 0.5 m_c^T Sigma_f^(-1) m_c`。

该模型仍由空间滤波、方差和线性判别组成，可显示 CSP pattern、源权重和类别原型。

### 5.1 配对统计

以每名确认受试者跨预算平均值做双侧 Wilcoxon 检验：

| 对比 | 平均提升 | p 值 |
|---|---:|---:|
| 层级 CSP vs 目标-only | **+4.37 pp** | **0.0098** |
| 层级 CSP vs 固定等权先验 | **+2.75 pp** | **0.0039** |
| 层级 CSP vs 仅相似度自适应 CSP | **+1.02 pp** | **0.0020** |
| 层级 CSP vs 源标签交换负控 | **+2.97 pp** | **0.0137** |

2-shot 相对目标-only 提升 7.08 pp，`p=0.0059`；相对固定先验提升 6.35 pp，`p=0.0020`。

标签交换负控显著更差，说明收益不是单纯增加源数据或正则化造成，而与正确源类别结构有关。

## 6. 被拒绝的模块

“源-目标类别差方向余弦一致性门控”跨预算平均只改变 `+0.04 pp`，`p=0.8457`，没有提供功能增益，应拒绝，不进入部署模型。

此前 Euclidean Alignment、多频带动态选择和复杂 Riemannian 候选也未稳定超过简单 CSP-LDA，继续保留为负结果。

## 7. 速度

当前离线单次 fit+predict 平均耗时：

- 目标-only CSP-LDA：约 8-9 ms。
- 相似度自适应 CSP-LDA：约 8-9 ms。
- 完整层级 CSP：约 24-27 ms。

在线部署只保留已训练的 6 个 CSP 滤波器、标准化参数、两个原型和共享精度矩阵，推理仍为 `O(KCT)`，不需要神经网络迭代。

## 8. 结论与限制

本轮创新通过了以下证据：

- 在完全未见的 10 名确认受试者上优于目标-only 和固定先验。
- 低样本 2-shot 提升最大。
- 标签交换负控支持正确源类别信息的作用。
- 数学结构和每个中间量均可解释。
- 训练和推理速度满足实时系统要求。

但绝对平衡准确率只有约 57%，个别受试者仍接近随机水平。该模型适合作为后续研究基线，尚不适合无拒识地驱动机械臂。真实系统必须增加：

1. 校准质量门槛和“不适用 MI”判定。
2. 概率置信度与拒识。
3. 跨 session 重测，而不是只做同 session 随机 trial 验证。
4. 咬肌动作存在时的同步 EEG/EMG 专项数据。
